# Pharmaceutical QA Sample Tracking Dashboard

## Overview
Showcasing excel-based quality assurance system for a mock pharmaceutical sample management. Features chain of custody tracking , process monitoring analytics.

## Key Features
- **Data Validation**: Controlled vocabulary for departments, status, and priority levels (GDP compliance)
- **VLOOKUP Integration**: Automated sample detail retrieval from Master Database
- **Conditional Formatting**: Real-time alerts for temperature excursions, rejections, and high-priority items
- **Pivot Table Analytics**: 
  - Peak time analysis (samples by hour)
  - Status bottleneck identification
  - Rejection trend analysis
- **KPI Dashboard**: At-a-glance metrics for QA oversight

## Skills Demonstrated
- Good Documentation Practices (GDP)
- Data integrity and validation
- Chain of custody protocols
- Statistical process monitoring
- Excel: PivotTables, VLOOKUP, Data Validation, Conditional Formatting

## Context
Created as portfolio project for QA Associate role in pharmaceutical manufacturing.
